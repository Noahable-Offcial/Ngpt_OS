# NGPT OS

A browser-based desktop-style workspace, ready for static deployment on Vercel.

## Deploy to Vercel
1. Import this GitHub repository in Vercel.
2. Choose the **Other** framework preset.
3. Leave the build command empty.
4. Set the output directory to `.` (the repository root), if prompted.
5. Deploy.

No API keys are needed for this preview.

## Included in the first preview
Desktop, Start menu, taskbar, draggable app windows, Browser, Files, App Store, Settings, Calculator, Calendar, Clock, and Paint.

**Browser note:** Some sites block embedding inside other websites. Use the Browser app's open-in-new-tab option for those sites. Notes are stored locally in your browser and do not sync between devices.
